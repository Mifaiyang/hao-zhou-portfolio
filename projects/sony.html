怎么做出来

把一条不稳定的链路
拆成四个能分别验证的环节

  1. 01

    先把麻烦说清楚

    我不需要炫技功能，只希望相机拍完后，素材可以在同一家庭网络里进入 Mac 的固定文件夹。

  2. 02

    把 AI 变成技术协作者

    我把设备、网络、安全边界和可用标准写清楚，由 AI 负责代码、命令配置和技术排错，我持续补充真实约束。

  3. 03

    在真实设备上逐项验证

    按照方案配置 Mac 和 Sony 相机，再把连接失败、菜单位置和传输情况反馈给 AI，直到照片能稳定进入指定文件夹。

  4. 04

    把一次解决整理成公开工具

    完成日常使用验收后，再整理为 GitHub 项目、AI Agent Skill 和小红书演示，让其他人可以查看配置思路和脚本。

真实使用之后

它解决了麻烦
也没有假装解决一切

最难配置

相机菜单像一座迷宫

Sony 的网络与 FTP 设置层级很深，找到正确入口、对应填写参数，是实际配置中最费时间的一部分。

速度限制

家庭网络不是高速读卡器

实际速度受 Wi-Fi 和网络环境影响，达不到理论上限。它更适合日常和小批量传输，而不是替代所有高速导卡场景。

使用频率

现在每周仍会用 1-2 次

它没有成为每天必开的功能，但在家拍完想快速把素材送进 Mac 时，仍然能少拿一次读卡器。
