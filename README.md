# 周灏个人网站

一份零依赖的静态个人网站，整合个人介绍、代表项目、商业成果与工作方法。

## 本地预览

在当前目录运行：

```bash
python3 -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/portfolio-site/`。

## 内容来源

公开文案与数据基于工作区中的《周灏-个人职业与项目全量母档-v1》整理。上线前建议补充个人肖像、项目成片封面和最新数据截图。

## 迭代备份规则

- 每次开始修改前，确认当前版本已经提交到 Git。
- 每完成一轮可查看的网站更新，提交一次 Git 备份。
- 提交信息使用中文，简要写明本轮修改内容，不把未确认版本标为“最终版”。
- 网站使用的压缩素材可以纳入版本；原始大视频统一放入 `素材原片/`，不提交到 Git。
