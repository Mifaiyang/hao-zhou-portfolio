# 周灏个人网站

一份零依赖的静态个人网站，整合个人介绍、代表项目、商业成果与工作方法。

## 本地预览

在网站仓库目录运行：

```bash
python3 -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。

也可以直接双击 `打开本地网站.command`。脚本会从自身位置找到网站目录；如果 4173 端口已被其他服务占用，会自动换到下一个可用端口。

## 内容来源

公开文案与数据基于工作区中的《周灏-个人职业与项目全量母档》整理。新增数据先回到母档核对，不从页面文案反推事实。

## 迭代备份规则

- 每次开始修改前，确认当前版本已经提交到 Git。
- 每完成一轮可查看的网站更新，提交一次 Git 备份。
- 提交信息使用中文，简要写明本轮修改内容，不把未确认版本标为“最终版”。
- 网站使用的压缩素材可以纳入版本；原始大视频统一放入 `素材原片/`，不提交到 Git。
