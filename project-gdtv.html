Case 06

广东广播电视台｜新媒体编辑与项目执行

相比普通短视频团队，电视台项目更重视内容规范、流程配合和播出稳定性。

Project Overview

广东广播电视台数字频道管理部承担电视端节目、新媒体矩阵内容和直播项目执行等工作。相比普通短视频团队，电视台项目更重视内容规范、流程配合和播出稳定性。

My Role

我担任新媒体编辑 / 项目执行，参与电视端新闻稿件、4K节目、新媒体短视频、直播间搭建和活动项目执行。

What I Did

News & Program 独立拍摄与剪辑电视端新闻稿件4条，参与4K超高清频道节目《爱宠校园》6集拍摄与剪辑。

New Media Content 参与移动频道官方矩阵账号短视频新闻资讯更新，完成短视频剪辑和发布支持。

Column & Live Clips 参与《年轻人的100个安家建议》栏目策划、抖音直播和切片制作。

Live Room Setup 参与从0搭建抖音线下团购访谈类直播间，负责灯光场景布置、技术调试和推流配置。

Event Execution 参与汕头市2025开海节项目执行，与甲方和供应商沟通宣传物料与拍摄计划。

Results

  • 独立完成4条电视端新闻稿件拍摄与剪辑
  • 参与完成《爱宠校园》6集节目拍摄与后期
  • 短视频新闻资讯单条播放量最高达100万+
  • 参与完成抖音线下团购访谈类直播间搭建与播出支持
  • 参与大型活动项目统筹和多方沟通执行

Reflection

这段经历让我接触到更规范的媒体内容生产流程，也训练了我在正式项目中的执行意识：内容要符合播出标准，直播要保证稳定，活动项目要兼顾甲方、供应商和现场情况。

它也让我从单纯的视频制作者，开始理解项目执行和内容协作的重要性。
